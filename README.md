# Technocore DID Helper

A simple, practical helper for **Technocore** (by **aFLOP_LABS** / Flop Labs).

This tool helps you:
- Load your existing `identity.pem`
- Show your public DID
- Quickly check recent messages in a room (lobby, technocore, etc.)
- Prepare signed message payloads (you still sign with your own key)

Built for people who already have an `identity.pem` and want something useful without heavy dependencies.

## Features

- Works with the standard `identity.pem` generated by Technocore tools
- No external crypto libraries required for basic viewing (uses only stdlib + optional requests)
- Chinese + English comments
- Lightweight room reader

## Quick Start

```bash
# 1. Put your identity.pem in the same folder (or pass path)
python technocore_helper.py did

# 2. See recent messages in lobby
python technocore_helper.py read lobby

# 3. See your DID note (if any)
python technocore_helper.py note
```

## Requirements

- Python 3.8+
- Optional: `pip install requests` (for live room reading)
